Malik est le propriétaire de Nouvelle Ardoise (agence marketing pour la restauration, Genève) et de Pasta Mo' ; il valide visuellement sur son téléphone et son Mac. Les revues sont demandées par un agent intégrateur qui travaille pour lui ; d'autres développeurs touchent le dépôt en parallèle.

**Règles de Malik (toute violation = bloquant)**
- Jamais d'alcool (ni verre, ni bouteille) dans un visuel.
- Rien ne bouge en HTML pendant que la craie écrit (images 6-54 et 234-258).
- Au doigt, chaque arrêt tombe sur une image stable, aucun arrêt sauté.
- Chargement rapide ; pas d'effet « vidéo » automatique : tout est au scroll.
- Texte en haut lisible sur téléphone ; pas de « cinq métiers ».

**Barème de gravité**
- bloquant = casse le site ou viole une règle ci-dessus ; majeur = visible par Malik ou risque réel sur téléphone ; mineur = qualité de code.

**How to apply:** calibrer honnêtement : une API de recette ou un attribut mal parsé qui ne touche pas le visiteur reste mineur. Voir [[feedback-cadre-revue]].
